**WOK HEI** — you run stall No. 7 in the night market: four woks, six
ingredients, a crowd that will not wait. Toss the right ingredients into the
right wok, mind the heat, and serve before patience runs out. Five nights,
rush hours, a gold shop between nights, five collectible relics, three usable
abilities — and Madame Golden Ladle, the food critic, arriving on night 5 with
signature dishes that must be tossed in exact sequence. Fill her approval bar
to 100% and earn the five stars. All art is drawn in code and all sound is
synthesized with WebAudio; the game runs offline from static files.

## Run it

```sh
npx serve game
# or: python3 -m http.server -d game
# then open http://localhost:8000 in desktop Chrome
```
